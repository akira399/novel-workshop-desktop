# 大肥鱼的小说工坊

> AI 小说创作工作台 · 独立 Windows 桌面软件

「大肥鱼的小说工坊」是一款面向网文作者的 **AI 小说创作工作台**，提供完整的 Windows 桌面创作体验。它把“选题构思、设定管理、章节写作、AI 润色、质量诊断、完整性检查、成稿导出”放进一个本地优先的工作台中，让作者可以专注于写作本身。

软件与同名 DSH 插件同源，并在桌面端扩展为更完整的创作工作台。

---

## ✨ 核心功能

### 📚 完整创作流程

内置网文创作的九阶段门禁流程：

1. 选题
2. 设定
3. 人设
4. 大纲
5. 分卷
6. 细纲
7. 正文
8. 修订
9. 完本

每个阶段都有产物落盘、版本快照与审计记录，帮助你按部就班推进一本书。

### 🧠 AI 写作助手（聊天控制台）

底部聊天框不只是聊天，而是**直接操控编辑框的 AI 控制入口**：

- AI 能实时读取当前编辑框正文与章节标题
- 通过自然语言下达指令，例如：
  - “按玄幻爽文的节奏生成第一章”
  - “给当前正文增加 100 字，描写主角心理”
  - “把这段改成第三人称”
  - “对当前章节做重构式润色”
- AI 会直接修改上方编辑框内容并自动写回，无需手动复制粘贴
- 普通写作咨询、设定问答、诊断分析等也支持

### ✍️ 专业文本编辑器

- 章节标题与正文分离编辑
- 撤销 / 重做
- 查找 / 替换
- 字号调整
- AI 一键写章与自动选中章节
- 本地草稿直接保存到磁盘

### 🤖 多模型自由接入

- 支持 OpenAI 兼容端点、DeepSeek、Moonshot Kimi、Anthropic、Google Gemini、Ollama（本地）、智谱 GLM、自定义提供商
- 同一提供方可保存多个模型，并批量导入模型列表
- 聊天框可随时切换当前模型
- API Key 仅保存在本地主进程，不会暴露给界面脚本

### 📖 世界书（Lorebook）管理

- 世界书条目：名称、关键词、优先级、常驻、启用/停用
- 多字段编辑面板
- 按书绑定 / 全局条目
- 世界书分组管理（新建、改名、启用、删除）
- AI 一键生成世界书设定
- SillyTavern 兼容导出 / Operit 导入
- 世界书 JSON 导入

### 🔍 质量与一致性

- AI 味检测 / 去 AI 味改写
- 黄金三章诊断
- 章节四族校验（结构 / 内容 / 剧情 / 一致性）
- 一致性巡检：账本冲突、时间线倒挂、伏笔超期
- 事实账本、时间线、伏笔、术语、灵感管理

### 🧩 创作工具箱

- 高级工具箱覆盖完整创作动作：阶段推进、阶段提交、审计、克隆项目、应用建议、AI 修订、字数统计、提示词库、意图解析、向导等
- 一键导入示例项目《青云问道》

### 📂 本地文件

- 新增 / 打开本地作品库
- 导入本地 txt / md 书籍文件（自动识别章节并建书）
- 本地素材 / 技能库
- 离线阅读：txt / md 内置阅读器；PDF / EPUB 调用系统默认程序打开

### 📤 导出与发布

- 文本导出：txt / markdown / 平台排版
- 电子书导出：EPUB / PDF / DOCX
- 导出时自动合并全书章节，支持分卷

### ☁️ 云同步

- WebDAV 协议
- 兼容坚果云、Nextcloud、自建 WebDAV
- 一键推送 / 拉取整个工作区备份

### 🔄 自动更新

- 通过 GitHub Releases 自动检查更新
- 支持增量下载与重启安装

## 🚀 快速开始

### 安装

1. 从 [GitHub Releases](https://github.com/akira399/novel-workshop-desktop/releases) 下载最新安装包：
   - `大肥鱼的小说工坊-<版本>-win-x64.exe`（安装版）
   - 或 `大肥鱼的小说工坊 <版本>.exe`（便携版，免安装）
2. 安装版按向导完成安装，便携版直接双击运行。

### 配置模型

1. 点击顶部「模型设置」
2. 选择提供方（如 DeepSeek、OpenAI、自定义）
3. 填写 Base URL 与 API Key
4. 点击「自动获取模型列表」并选择/输入模型名
5. 保存模型，并在聊天框左侧下拉切换当前模型

### 开始创作

1. 点击侧边栏「＋」新建作品
2. 输入书名与题材
3. 选中作品后，侧边栏出现章节与 AI 操作按钮
4. 点击「AI 写章」即可生成第一章，或在底部聊天框直接下达写作指令
5. 编辑完成后点击「保存」

## 🛠 开发与构建

```bash
# 安装依赖
pnpm install

# 运行测试
pnpm test

# 启动开发模式
pnpm --filter @dafuyu/desktop dev

# 构建并打包 Windows 安装包 + 便携版
pnpm --filter @dafuyu/desktop package:win
```

### 快速测试（免安装）

```bash
pnpm quick
```

或手动构建免安装目录：

```bash
pnpm --filter @dafuyu/desktop build:dir
```

然后双击 `apps/desktop/run-unpacked.bat`，或直接运行 `apps/desktop/release/win-unpacked/大肥鱼的小说工坊.exe`。
